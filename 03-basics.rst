基础语法与表达式
================================================================================

Haskell 的语法风格与传统的 C 族语言截然不同。在这里，程序由\ **纯净的表达式**\ 构成，不存在命令式语言中的“变量赋值”与“语句顺序执行”概念。

代码注释与排版缩进规则
--------------------------------------------------------------------------------

单行与多行注释
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. code:: haskell

   -- 这是单行注释

   {-
     这是多行块级注释。
     {- 多行注释还支持安全嵌套 -}
   -}

越界缩进规则（Layout / Offside Rule）
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

与 Python 类似，Haskell 使用\ **缩进**\ 而非大括号与分号来确定代码块的作用域边界。这套机制在语言规范中被称为\ **越界规则（Offside Rule）**\ ：

1. **同级对齐原则**\ ：处于同一个逻辑块（如 ``where``\ 、\ ``let`` 或 ``do``\ ）内的多个声明，必须严格保持相同的起始列缩进。
2. **续行缩进原则**\ ：如果一个长表达式拆分为多行，后续行必须比起始声明行具有更深的缩进。
3. **禁止使用 Tab 制表符**\ ：不同编辑器对制表符宽度的解释不同，极易引发编译器排版解析错乱。请始终在编辑器中配置为\ **纯空格缩进**\ （通常建议为 2 格或 4 格）。

.. code:: haskell

   -- 正确对齐示例：
   calculateValues :: Double -> (Double, Double)
   calculateValues x = (firstVal, secondVal)
     where
       firstVal  = x * 2 + 1   -- 严格同列对齐
       secondVal = x ^ 2 + 3

表达式与不可变绑定
--------------------------------------------------------------------------------

在 Haskell 中，所有数据一旦创建就\ **完全不可变**\ 。我们通过名称将表达式绑定到某个标识符：

.. code:: haskell

   x = 10
   y = 20
   z = x + y

这里的 ``=`` 代表数学意义上的\ **恒等定义**\ 与\ **命名绑定**\ ，而不是内存地址的“覆写赋值”。在同一作用域内，同一个名称不能被重复绑定。

算术运算与负数陷阱
--------------------------------------------------------------------------------

常用的基本算术运算符包括：

- 加法：\ ``+``
- 减法：\ ``-``
- 乘法：\ ``*``
- 浮点除法：\ ``/``\ （例如 ``7 / 2`` 结果为 ``3.5``\ ）
- 整数整除：\ ``div``
- 整数取模：\ ``mod``

.. code:: text

   ghci> 7 / 2
   3.5
   ghci> div 7 2
   3
   ghci> mod 7 2
   1

负数的语法陷阱
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Haskell 中的 ``-`` 既是二元减法运算符，也是一元负号。为了避免语法歧义，\ **所有作为参数传递的负数都必须用圆括号包裹**\ ：

.. code:: text

   ghci> 10 + (-3)
   7
   ghci> 10 + -3    -- 语法错误！编译器无法解析两个连续的中缀操作符

中缀运算符、前缀函数与截断（Sectioning）
--------------------------------------------------------------------------------

中缀与前缀转换
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

在 Haskell 中，操作符与普通函数之间可以无缝双向转换：

1. **中缀转前缀**\ ：用圆括号包裹任何中缀运算符，即可当作普通前缀函数调用：

   .. code:: text

      ghci> (+) 10 20
      30
      ghci> (*) 5 6
      30

2. **前缀转中缀**\ ：用反引号包裹双参数函数名（例如 ``10 `div` 2``\ ），即可作为中缀运算符使用：

   .. code:: text

      ghci> 10 `div` 2
      5
      ghci> 17 `mod` 5
      2

操作符截断（Operator Sectioning）
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

用圆括号包裹中缀运算符及其单侧参数，可以极速构造单参数柯里化函数：

- **左侧截断**\ ：\ ``(2 ^)`` 等价于 ``\x -> 2 ^ x`` （以 2 为底的指数运算）。
- **右侧截断**\ ：\ ``(^ 2)`` 等价于 ``\x -> x ^ 2`` （求平方）。
- **除法截断**\ ：\ ``(/ 2)`` 表示除以 2（折半函数）。

.. warning::

   **一元减号的截断陷阱**\ ：
   特别注意，表达式 ``(- 2)`` 在 Haskell 中并不表示“减去 2 的函数”，而是表示\ **负数 -2 本身**\ ！
   如果需要表达“减去 2”的函数，必须使用标准库提供的函数：\ ``subtract 2`` 或显式 Lambda：\ ``\x -> x - 2``\ 。

优先级与结合性
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Haskell 中的函数调用拥有最高的优先级（优先级 10），其结合性为左结合：

.. code:: text

   f x + g y  -- 等价于 (f x) + (g y)，绝不会被解析为 f (x + g) y

每一个中缀操作符都有对应的优先级（0 到 9）和结合性（左结合 ``infixl``\ 、右结合 ``infixr``\ 、无结合 ``infix``\ ）。可以在 GHCi 中使用 ``:i`` 查看：

.. code:: text

   ghci> :i (+)
   infixl 6 +
   ghci> :i (*)
   infixl 7 *
   ghci> :i (^)
   infixr 8 ^

乘法优先级为 7，高于加法的 6，因此 ``2 + 3 * 4`` 会先计算乘法；而乘方 ``^`` 是优先级为 8 的右结合操作符，因此 ``2 ^ 3 ^ 2`` 等价于 ``2 ^ (3 ^ 2) = 512``\ 。

局部作用域：let 与 where
--------------------------------------------------------------------------------

当我们需要在局部范围定义临时变量或辅助函数时，Haskell 提供了两种优雅的语法：\ ``let ... in ...`` 和 ``where``\ 。

let 表达式
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

``let`` 是一种\ **一等表达式**\ ，具有独立的返回值，可以嵌套在任何允许表达式出现的位置：

.. code:: haskell

   cylinderArea :: Double -> Double -> Double
   cylinderArea r h =
     let sideArea = 2 * pi * r * h
         topArea  = pi * r ^ 2
     in  sideArea + 2 * topArea

where 子句
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

``where`` 是\ **声明级语法**\ ，紧跟在函数定义的方程右侧，用于为整个函数（包括其守卫分支）提供辅助定义：

.. code:: haskell

   cylinderArea' :: Double -> Double -> Double
   cylinderArea' r h = sideArea + 2 * topArea
     where
       sideArea = 2 * pi * r * h
       topArea  = pi * r ^ 2

二者选型指南：

- ``let`` 适合小范围临时值计算或嵌套在列表推导式、单子代码块中。
- ``where`` 视觉上强调“主计算逻辑在顶层，辅助细节在下方”，代码自顶向下阅读体验更优。

字符、字符串与基础列表操作
--------------------------------------------------------------------------------

- **字符（Char）**\ ：单引号包裹的单个 Unicode 字符，如 ``'a'``\ 、\ ``'中'``\ 。
- **字符串（String）**\ ：双引号包裹，在底层等价于字符的链表 ``[Char]``\ 。

常用基础列表操作：

- 列表拼接：\ ``++``
- 头部添加元素（Cons）：\ ``:``
- 获取首元素：\ ``head`` （警惕空列表偏函数崩溃）
- 获取尾部列表：\ ``tail`` （警惕空列表偏函数崩溃）
- 截取前 N 个元素：\ ``take``
- 舍弃前 N 个元素：\ ``drop``
- 列表长度：\ ``length``

.. code:: text

   ghci> 'H' : "ello"
   "Hello"
   ghci> "Hello, " ++ "World!"
   "Hello, World!"
   ghci> take 2 "Haskell"
   "Ha"
   ghci> drop 2 "Haskell"
   "skell"

偏函数崩溃与安全替代方案
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

在空列表上调用 ``head []`` 或 ``tail []`` 会导致致命运行时异常：

.. code:: text

   ghci> head []
   *** Exception: Prelude.head: empty list

在生产代码中，应坚决避免直接调用 ``head`` 与 ``tail``\ ，优先采用模式匹配，或使用来自 ``Data.List`` 的安全解构函数 ``uncons``\ ：

.. code:: haskell

   import Data.List (uncons)

   -- uncons :: [a] -> Maybe (a, [a])
   safeHead :: [a] -> Maybe a
   safeHead xs = case uncons xs of
     Nothing      -> Nothing
     Just (h, _)  -> Just h

小结
--------------------------------------------------------------------------------

- Haskell 使用纯空格缩进（Offside Rule）划定声明块边界，坚决避免使用制表符 Tab。
- 中缀操作符可使用 ``(op)`` 转为前缀，前缀函数可使用反引号包裹转为中缀。
- 操作符截断支持单侧填参，但减法需使用 ``subtract 2`` 规避一元负号歧义。
- 函数应用优先级最高（10），操作符结合性决定求值次序。
- 杜绝直接使用 ``head``\ /\ ``tail`` 偏函数，善用模式匹配与全函数保障系统健壮性。
