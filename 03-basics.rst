基础语法与表达式
================================================================================

Haskell 的语法风格与传统的 C 族语言截然不同。在这里，程序由\ **纯净的表达式**\ 构成，不存在命令式语言中的“赋值”概念。

代码注释
--------------------------------------------------------------------------------

Haskell 支持单行与多行注释：

.. code:: haskell

   -- 这是单行注释

   {-
     这是多行注释。
     可以跨越任意多行。
   -}

表达式与不可变绑定
--------------------------------------------------------------------------------

在 Haskell 中，所有数据一旦创建就\ **完全不可变**\ 。我们通过名称将表达式绑定到某个标识符：

.. code:: haskell

   x = 10
   y = 20
   z = x + y

这里的 ``=`` 代表数学意义上的\ **恒等**\ 与\ **绑定**\ ，而不是内存位置的“赋值”。在同一作用域内，同一个名称不能被重复绑定。

算术运算与负数
--------------------------------------------------------------------------------

常用的基本算术运算符包括：

- 加法：\ ``+``
- 减法：\ ``-``
- 乘法：\ ``*``
- 浮点除法：\ ``/``\ （例如 ``5 / 2`` 结果为 ``2.5``\ ）
- 整除与取模：\ ``div`` 与 ``mod``

.. code:: text

   ghci> 7 / 2
   3.5
   ghci> div 7 2
   3
   ghci> mod 7 2
   1

负数的陷阱
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Haskell 中的 ``-`` 既是二元减法运算符，也是一元负号。为了避免语法歧义，\ **所有作为参数传递的负数都必须用圆括号包裹**\ ：

.. code:: text

   ghci> 10 + (-3)
   7
   ghci> 10 + -3    -- 报错！语法无法解析两个连续运算符

中缀运算符与前缀函数
--------------------------------------------------------------------------------

在 Haskell 中，操作符与普通函数之间可以无缝转换：

1. **中缀转前缀**\ ：用圆括号包裹任何中缀运算符，即可当作普通前缀函数调用：

   .. code:: text

      ghci> (+) 10 20
      30
      ghci> (*) 5 6
      30

2. **前缀转中缀**\ ：用反引号包裹函数名（例如 ``10 `div` 2``\ ），即可作为中缀运算符使用：

   .. code:: text

      ghci> 10 `div` 2
      5
      ghci> 17 `mod` 5
      2

优先级与结合性
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

每一个运算符都有对应的优先级（0 到 9）和结合性（左结合、右结合、无结合）。可以在 GHCi 中使用 ``:i`` 查看：

.. code:: text

   ghci> :i (+)
   infixl 6 +
   ghci> :i (*)
   infixl 7 *

``infixl 6`` 表示 ``+`` 是优先级为 6 的左结合运算符；乘法优先级为 7，因此 ``2 + 3 * 4`` 先计算乘法。

局部作用域：let 与 where
--------------------------------------------------------------------------------

当我们需要在局部范围定义临时变量或辅助函数时，Haskell 提供了两种优雅的语法：\ ``let ... in ...`` 和 ``where``\ 。

let 表达式
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

``let`` 是一种\ **表达式**\ ，具有独立的返回值，可以嵌套在任何需要表达式的地方：

.. code:: haskell

   cylinderArea :: Double -> Double -> Double
   cylinderArea r h =
     let sideArea = 2 * pi * r * h
         topArea  = pi * r ^ 2
     in  sideArea + 2 * topArea

where 子句
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

``where`` 是\ **声明级语法**\ ，紧跟在函数定义的右侧，用来提供支持上下文的辅助定义：

.. code:: haskell

   cylinderArea' :: Double -> Double -> Double
   cylinderArea' r h = sideArea + 2 * topArea
     where
       sideArea = 2 * pi * r * h
       topArea  = pi * r ^ 2

区别与选择：

- ``let`` 是一个一等表达式，其作用域仅限于 ``in`` 之后的内容。
- ``where`` 语法绑定在整个函数定义（包括守卫子句），视觉上更利于自顶向下的阅读体验。

字符、字符串与基础列表操作
--------------------------------------------------------------------------------

- **字符（Char）**\ ：单引号包裹的 Unicode 字符，如 ``'a'``\ 、\ ``'中'``\ 。
- **字符串（String）**\ ：双引号包裹，如 ``"Haskell"``\ 。在底层，\ ``String`` 等价于字符列表 ``[Char]``\ 。

常用基础操作：

- 列表拼接：\ ``++``
- 元素插入列表头部（Cons）：\ ``:``
- 获取首元素：\ ``head``
- 获取尾部列表：\ ``tail``
- 截取前 N 个元素：\ ``take``
- 舍弃前 N 个元素：\ ``drop``
- 列表长度：\ ``length``

.. code:: text

   ghci> 'H' : "ello"
   "Hello"
   ghci> "Hello, " ++ "World!"
   "Hello, World!"
   ghci> head [1, 2, 3]
   1
   ghci> tail [1, 2, 3]
   [2, 3]
   ghci> take 2 "Haskell"
   "Ha"
   ghci> drop 2 "Haskell"
   "skell"

小结
--------------------------------------------------------------------------------

- Haskell 中的绑定是不可变的，一切通过纯表达式求值。
- 中缀操作符与前缀函数可通过 ``(op)`` 与 `\ ``func``\ ` 双向转换。
- ``let ... in`` 用于局部表达式求值，\ ``where`` 用于声明级别的辅助定义。
- 字符串在本质上就是 ``Char`` 的链表。
