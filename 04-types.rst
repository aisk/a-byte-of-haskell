基本数据类型、类型推断与类型别名
================================================================================

类型系统是 Haskell 最核心的支柱。Haskell 拥有强大的静态强类型系统，具备极其严密的编译期检查与高精度的自动\ **类型推断**\ （基于 Hindley-Milner 算法体系）。掌握类型系统的思维方式，是编写高质量 Haskell 代码的根本。

常见内置基本数据类型
--------------------------------------------------------------------------------

布尔型（Bool）
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

布尔类型仅包含两个合法值：\ ``True`` 与 ``False``\ 。定义在标准库中：

.. code:: haskell

   data Bool = False | True

常用逻辑运算：与（\ ``&&``\ ）、或（\ ``||``\ ）、非（\ ``not``\ ）。

数值类型系统
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Haskell 将整数与实数细分为多种具备不同性能与数学特性的具体类型：

- **Int**\ ：固定精度的有符号整数（通常对齐机器字长，在 64 位系统上为 64 位整型，范围约为 -2⁶³ ～ 2⁶³-1）。其底层直接映射到 CPU 原生机器字长，运算性能极高。
- **Integer**\ ：任意精度的整数，只要物理内存充裕，它可以表示任意巨大的数字而\ **永远不会溢出**\ 。常用于密码学、大数精确计算等领域。
- **Float**\ ：单精度 32 位 IEEE 754 浮点数。
- **Double**\ ：双精度 64 位 IEEE 754 浮点数，是日常科学计算与工程浮点运算的默认推荐类型。

字符与字符串
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- **Char**\ ：单个 Unicode 字符，用单引号表示，如 ``'a'``\ 、\ ``'中'``\ 、\ ``'λ'``\ 。
- **String**\ ：双引号表示的字符串，在底层它是一个普通的字符链表 ``[Char]``\ 。

复合容器类型：元组与列表
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- **元组（Tuple）**\ ：异构、固定长度容器。例如 ``("Alice", 28, True) :: (String, Int, Bool)``\ 。
  二元组是最常见的元组，标准库提供了快速访问函数：

  - ``fst :: (a, b) -> a``\ ：提取第一个元素。
  - ``snd :: (a, b) -> b``\ ：提取第二个元素。

- **单元类型（Unit / ()）**\ ：空元组 ``()`` 既是一个类型，也是该类型的唯一合法值。它代表“没有任何实质信息”，类似于 C/Java 中的 ``void``\ 。
- **列表（List）**\ ：同构、动态长度容器。例如 ``[1, 2, 3] :: [Int]``\ 。

类型别名（Type Synonyms）
--------------------------------------------------------------------------------

除了使用 ``data`` 声明全新类型，Haskell 允许使用 ``type`` 关键字为现有类型声明一个更具业务语义的\ **别名（Synonym）**\ ：

.. code:: haskell

   -- 标准库中 String 的本质就是类型别名：
   type String = [Char]

   -- 在业务代码中赋予语义：
   type PhoneNumber = String
   type UserID      = Integer
   type Coordinates = (Double, Double)

.. note::

   **类型别名的特征与限制**\ ：
   类型别名在编译期完全等价于其底层类型，仅仅是为了提升代码可读性。编译器不会阻止你将一个普通的 ``String`` 传给期待 ``PhoneNumber`` 的函数。
   此外，类型别名**不能被部分应用**\ （除非开启高级语言扩展）。如果你需要物理层面的绝对类型隔离与独立类型类实例，应当使用 ``newtype``\ 。

.. list-table:: data、newtype 与 type 三者对比
   :widths: 20 25 25 30
   :header-rows: 1

   * - 关键字
     - 运行期开销
     - 构造器数量限制
     - 适用场景
   * - ``type``
     - 零开销（编译期纯别名替换）
     - 无数据构造器
     - 提高代码可读性与长类型签名简写
   * - ``newtype``
     - 零开销（编译后自动剥除外壳）
     - 严格单一构造器且单字段
     - 轻量级强类型隔离、赋予独立 Typeclass 实例
   * - ``data``
     - 存在装箱与数据构造器指针开销
     - 任意多构造器、任意多字段
     - 定义全新的和类型（Sum）与积类型（Product）

类型阶数：Kind（类型的类型）
--------------------------------------------------------------------------------

正如普通表达式与值拥有“类型”（Type）一样，\ **类型自身也拥有属于它的元分类——阶数（Kind）**\ 。

在 GHCi 中使用 ``:kind`` 或简写 ``:k`` 可以查询任何类型的阶数：

1. **具体类型（Kind 为 ``*`` 或 ``Type``\ ）**\ ：
   凡是能够直接承载实际运行期值的类型，其 Kind 均为 ``*``\ ：

   .. code:: text

      ghci> :k Int
      Int :: *
      ghci> :k Bool
      Bool :: *
      ghci> :k [Char]
      [Char] :: *

2. **类型构造器（高阶 Kind）**\ ：
   正如函数接收一个值并产出另一个值（类型形如 ``a -> b``\ ），某些类型必须接收其他具体类型作为参数，才能组合成一个完整类型。这种需要参数的类型被称为\ **类型构造器**\ ：

   .. code:: text

      ghci> :k []
      [] :: * -> *
      ghci> :k Maybe
      Maybe :: * -> *
      ghci> :k Either
      Either :: * -> * -> *

   ``Maybe`` 的 Kind 是 ``* -> *``\ ，意味着它必须“吃掉”一个具体类型（例如 ``Int :: *``\ ），才能变成一个可以存储具体值的完整类型（\ ``Maybe Int :: *``\ ）。

理解 Kind 是后续掌握 ``Functor``\ 、\ ``Monad`` 等高阶抽象类型类的最关键基石。

函数类型、柯里化与部分应用
--------------------------------------------------------------------------------

在类型签名中，符号 ``::`` 读作“具有……类型”。函数类型用右结合箭头 ``->`` 表达：

.. code:: haskell

   add :: Int -> Int -> Int
   add x y = x + y

因为箭头在类型层面上是\ **右结合**\ 的，所以：

.. code:: text

   Int -> Int -> Int  等价于  Int -> (Int -> Int)

这揭示了 Haskell 函数的数学本质——\ **所有函数严格只接收单一参数**\ 。多参数函数通过一层层嵌套返回新函数实现，这就是\ **柯里化（Currying）**\ 。

基于柯里化，我们可以随时进行\ **部分应用（Partial Application）**\ ：

.. code:: text

   ghci> add5 = add 5
   ghci> :t add5
   add5 :: Int -> Int
   ghci> add5 10
   15

多态性：参数多态与约束多态
--------------------------------------------------------------------------------

参数多态（Parametric Polymorphism）
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

当一个函数可以适用于任何数据类型时，我们在签名中使用小写字母表示的\ **类型变量**\ ：

.. code:: haskell

   -- 恒等函数：适用于任何类型 a
   id :: a -> a
   id x = x

   -- 恒常函数：丢弃第二个参数，返回第一个参数
   const :: a -> b -> a
   const x _ = x

约束多态（Constrained Polymorphism）
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

如果类型变量受到某种操作能力的约束（例如要求支持加法或比较大小），我们在胖箭头 ``=>`` 左侧标注类型类约束：

.. code:: haskell

   -- 要求类型 a 必须实现 Num 类型类
   square :: Num a => a -> a
   square x = x * x

数值类型转换陷阱与 fromIntegral
--------------------------------------------------------------------------------

这是所有从命令式语言转向 Haskell 的初学者最常踩到的坑：\ **Haskell 严禁隐式类型提升（Implicit Coercion）**\ 。

在 C 或 Python 中，\ ``5 + 3.14`` 会自动将整数 5 提升为浮点数完成相加。但在 Haskell 中：

.. code:: text

   ghci> x = 5 :: Int
   ghci> y = 3.14 :: Double
   ghci> x + y
   <interactive>: error:
       • Couldn't match expected type 'Int' with actual type 'Double'

此外，普通除法运算符 ``(/) :: Fractional a => a -> a -> a`` 只能用于浮点数，不能用于 ``Int``\ ：

.. code:: text

   ghci> (5 :: Int) / 2
   <interactive>: error:
       • No instance for (Fractional Int) arising from a use of '/'

桥梁函数：fromIntegral
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

为了在整数与浮点数之间进行计算，必须显式使用 ``fromIntegral``\ ：

.. code:: haskell

   fromIntegral :: (Integral a, Num b) => a -> b

它能将任何整数类型（如 ``Int``\ 、\ ``Integer``\ ）提升为任何通用的数值类型：

.. code:: text

   ghci> fromIntegral (5 :: Int) + (3.14 :: Double)
   8.14
   ghci> fromIntegral (5 :: Int) / 2
   2.5

常见 GHC 类型错误排查速查
--------------------------------------------------------------------------------

1. 类型不匹配错误
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. code:: text

   Couldn't match expected type 'X' with actual type 'Y'

- **原因**\ ：函数预期接受类型为 ``X`` 的实参，但调用者传递了类型为 ``Y`` 的表达式。
- **解决思路**\ ：检查入参位置，使用 ``:t`` 分别查看目标参数与输入表达式的类型。

2. 缺失类型类实例错误
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. code:: text

   No instance for (Show (Int -> Int)) arising from a use of 'print'

- **原因**\ ：试图打印一个函数 ``(Int -> Int)``\ ，但函数类型没有实现 ``Show`` 类型类。
- **解决思路**\ ：确认是否给多参数函数少传了参数，导致表达式本身还是一个未执行完毕的中间函数。

小结
--------------------------------------------------------------------------------

- Haskell 类型系统在编译期强力把关，支持 Hindley-Milner 自动类型推断。
- 值的抽象是 Type（Kind 为 ``*``\ ），类型的抽象是 Kind（如 ``* -> *``\ ）。
- ``type`` 用于语义别名，\ ``newtype`` 用于零开销类型封装，\ ``data`` 用于全新数据定义。
- 严禁隐式类型提升，数值混用需显式借助 ``fromIntegral`` 进行桥接转换。
