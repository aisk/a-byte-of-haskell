函数式思维与 Lambda 演算
================================================================================

Haskell 是一门 **纯函数式编程语言** 。要真正理解 Haskell 的设计哲学与代码表达方式，必须从它的数学根基—— **Lambda 演算** （λ-calculus）出发。

什么是纯函数式编程？
--------------------------------------------------------------------------------

在传统的命令式语言（如 C、Python、Java）中，程序是一系列改变计算机内部状态的“指令”。而在纯函数式编程中：

1. **计算即表达式求值**\ ：程序由纯函数与表达式构成，执行程序就是不断对表达式求值的过程。
2. **纯函数（Pure Functions）**\ ：函数的输出完全由输入决定。相同的输入必定产生完全相同的输出。
3. **引用透明性（Referential Transparency）**\ ：任何表达式都可以直接用它的求值结果替换，而不会改变整个程序的运行行为。
4. **无隐式副作用（No Implicit Side Effects）**\ ：函数执行不会暗中修改全局变量、修改外部文件或更改入参状态。

这种纯粹性使得函数式代码极易进行推理、测试和并发扩展。

Lambda 演算的结构
--------------------------------------------------------------------------------

Lambda 演算是逻辑学家阿隆佐·邱奇（Alonzo Church）在 20 世纪 30 年代提出的形式系统，用来形式化研究函数定义、函数应用与递归。在 Lambda 演算的世界里，\ **一切计算皆为函数**\ 。

一个 Lambda 项由三部分组成：

- **变量（Variables）**\ ：例如 ``x``\ 、\ ``y``\ 。
- **抽象（Abstraction）**\ ：定义一个函数。由头部（head）和主体（body）构成。
  记作 ``λx.x``\ 。
  其中 ``λx`` 是头部，\ ``x`` 是形参；点号 ``.`` 之后的 ``x`` 是函数主体。
- **应用（Application）**\ ：将函数作用于某个参数。记作：\ ``(λx.x) y``\ 。

绑定变量与自由变量
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

观察函数 ``λx.xy``\ ：

- ``x`` 在头部被声明，被称为\ **绑定变量（Bound Variable）**\ 。
- ``y`` 未在头部出现，由外部环境决定，被称为\ **自由变量（Free Variable）**\ 。

Beta 约简（Beta Reduction）
--------------------------------------------------------------------------------

计算的本质就是\ **约简（Reduction）**\ 。当我们把一个实参传递给函数时，就发生了\ **β-约简**\ ：将函数体内部所有绑定变量替换为实参，并消除函数头部的形参声明。

基础约简
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

恒等函数应用于值 ``2``\ ：

.. code:: text

   (λx.x) 2
   => 2

再看稍微复杂的表达式：

.. code:: text

   (λx.x + 1) 2
   => 2 + 1
   => 3

多参数与柯里化（Currying）
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

在纯 Lambda 演算中，\ **每个函数严格只接受一个参数**\ 。那么如何表达需要多个参数的计算？

答案是通过函数的嵌套——每个函数接受一个参数，并返回另一个接受下一个参数的函数。这种机制被称为\ **柯里化（Currying）**\ 。

例如两数相加的函数：

.. code:: text

   λx.λy.x + y

当我们对其传入两个参数进行连续求值：

.. code:: text

   ((λx.λy.x + y) 1) 2
   => (λy.1 + y) 2
   => 1 + 2
   => 3

在 Haskell 中，所有函数本质上都遵守这一柯里化模型。

范式与发散
--------------------------------------------------------------------------------

Beta 范式（Beta Normal Form）
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

当一个 Lambda 项经过若干次约简，不再包含任何可以继续应用的函数项时，该项就达到了\ **Beta 范式**\ （即计算完成的最终值）。

发散（Divergence）
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

并非所有表达式都能约简至范式。考虑著名的 Ω 组合子：

.. code:: text

   (λx.x x) (λx.x x)

对其进行约简：将实参 ``(λx.x x)`` 代入形参 ``x`` 中，得到的依然是：

.. code:: text

   (λx.x x) (λx.x x)

无论约简多少步，表达式永远无法停机并得到最终结果。在编程语言中，这种死循环或无法完成求值的情况被称为\ **发散（Divergence）**\ 。在 Haskell 中，这种概念被抽象为 **底（Bottom，记作 ⊥）** 。

小结
--------------------------------------------------------------------------------

- Haskell 建立在严格的 Lambda 演算基础之上，计算即表达式的约简与替换。
- 函数是一等公民，且单参数是函数的本质，多参数通过柯里化实现。
- 纯函数没有隐藏状态与副作用，支持基于数学逻辑的等式推理。
