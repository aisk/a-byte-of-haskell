递归与计算模型
================================================================================

因为 Haskell 中的变量是不可变的，我们无法使用 ``while (i < n) { i++; }`` 这样的状态自增循环。在纯函数式语言中，所有的重复性计算都自然地通过\ **递归**\ 来表达。

递归的两大法则
--------------------------------------------------------------------------------

设计任何递归函数时，必须明确两个核心部分：

1. **基准条件（Base Case）**\ ：计算的终止点，直接返回结果，不再进行递归调用。
2. **递归步骤（Recursive Step）**\ ：将复杂问题拆分为一个或多个更小规模的同类子问题，逐步向基准条件逼近。

典型范例
--------------------------------------------------------------------------------

阶乘函数（Factorial）
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

定义非负整数的阶乘：

.. code:: haskell

   factorial :: Integer -> Integer
   factorial 0 = 1                       -- 基准条件
   factorial n
     | n > 0     = n * factorial (n - 1) -- 递归步骤
     | otherwise = error "输入必须为非负整数"

推导过程：

.. code:: text

   factorial 3
   => 3 * factorial 2
   => 3 * (2 * factorial 1)
   => 3 * (2 * (1 * factorial 0))
   => 3 * (2 * (1 * 1))
   => 6

斐波那契数列（Fibonacci）
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. code:: haskell

   fib :: Int -> Integer
   fib 0 = 0
   fib 1 = 1
   fib n = fib (n - 1) + fib (n - 2)

从零实现整除与余数
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

通过重复减法实现带余除法，直观展现状态的递归传递：

.. code:: haskell

   dividedBy :: Integral a => a -> a -> (a, a)
   dividedBy num denom = go num denom 0
     where
       go n d count
         | n < d     = (count, n)            -- 余数小于除数，终止
         | otherwise = go (n - d) d (count + 1)

发散与底（Bottom / $\bot$）
--------------------------------------------------------------------------------

在类型理论中，\ **底**\ （写作 $\bot$ 或 Bottom）指代那些\ **无法计算出有效结果的计算**\ 。主要表现为两种情况：

1. **非终止计算**\ ：无限死循环（发散）。
2. **运行时异常**\ ：例如调用了标准库中的 ``error "msg"`` 或 ``undefined``\ 。

.. code:: text

   ghci> let loop = loop in loop
   -- 挂起，永不返回，对应底

偏函数（Partial Functions）之殇
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

如果一个函数在某些合法输入下没有定义对应的返回值（即会抛出异常或返回底），该函数就被称为\ **偏函数**\ 。

标准库中的 ``head`` 就是典型的偏函数：

.. code:: text

   ghci> head []
   *** Exception: Prelude.head: empty list

在生产实践中，偏函数是运行期崩溃的主要源头之一。Haskell 提倡编写\ **全函数（Total Functions）**\ ，即对域内的所有输入都有明确的安全输出。后续章节将介绍如何用类型（如 ``Maybe``\ ）彻底消灭此类问题。
