递归与计算模型
================================================================================

因为 Haskell 中的变量与数据结构完全不可变，我们无法使用类似 ``while (i < n) { i++; }`` 这样的可变计数器循环。在纯函数式语言中，所有的重复性计算与状态演化都自然地通过\ **递归（Recursion）**\ 来表达。

递归的两大法则
--------------------------------------------------------------------------------

设计任何递归函数时，必须明确两个核心部分：

1. **基准条件（Base Case）**\ ：计算的终止点，直接返回结果，不再进行递归调用。
2. **递归步骤（Recursive Step）**\ ：将复杂问题拆分为一个或多个更小规模的同类子问题，逐步向基准条件逼近。

典型基础范例
--------------------------------------------------------------------------------

阶乘函数（Factorial）
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

定义非负整数的阶乘：

.. code:: haskell

   factorial :: Integer -> Integer
   factorial 0 = 1                       -- 基准条件
   factorial n
     | n > 0     = n * factorial (n - 1) -- 递归步骤
     | otherwise = error "输入必须为非负整数"

推导展开过程：

.. code:: text

   factorial 3
   => 3 * factorial 2
   => 3 * (2 * factorial 1)
   => 3 * (2 * (1 * factorial 0))
   => 3 * (2 * (1 * 1))
   => 6

斐波那契数列（Fibonacci）
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. code:: haskell

   fib :: Int -> Integer
   fib 0 = 0
   fib 1 = 1
   fib n
     | n > 1     = fib (n - 1) + fib (n - 2)
     | otherwise = error "输入必须为非负整数"

整除与余数：状态的安全递归传递
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

通过重复减法实现带余除法，直观展现状态的递归传递，同时做好除数为非正数的严格防守：

.. code:: haskell

   dividedBy :: Integral a => a -> a -> (a, a)
   dividedBy _ 0 = error "除数不能为零"
   dividedBy num denom
     | denom < 0 = let (q, r) = dividedBy num (-denom) in (-q, r)
     | num < 0   = let (q, r) = dividedBy (-num) denom in (-q - 1, denom - r)
     | otherwise = go num denom 0
     where
       go n d count
         | n < d     = (count, n)            -- 余数已小于除数，达到基准条件
         | otherwise = go (n - d) d (count + 1)

尾递归与累加器模式（Accumulator Pattern）
--------------------------------------------------------------------------------

观察前面的普通递归 ``factorial``\ ：

.. code:: haskell

   factorial n = n * factorial (n - 1)

在计算返回前，当前函数调用帧必须在内存中等待 ``factorial (n - 1)`` 的结果，导致产生深度为 **O(n)** 的调用栈或待计算表达式树。

为了优化空间复杂度，我们引入\ **尾递归（Tail Recursion）**\ ：函数的最后一步操作是且仅是对自身的调用，无需保留当前栈帧。

累加器模式实现
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

通过引入一个局部的辅助函数 ``go`` 并携带一个保存中间聚合结果的\ **累加器（Accumulator）**\ ：

.. code:: haskell

   factorialTail :: Integer -> Integer
   factorialTail n
     | n < 0     = error "输入必须为非负整数"
     | otherwise = go n 1
     where
       go 0 !acc = acc
       go k !acc = go (k - 1) (k * acc)

.. note::

   在 Haskell 中，由于惰性求值特性，仅写成尾递归形式有时仍可能在累加器中堆积未求值的 Thunk。使用 ``!acc`` （来自 ``BangPatterns`` 语言扩展）或 ``seq`` 强制累加器在每一步完成求值，才能确保其达到常数空间 **O(1)** 的最优运行效率。

相互递归（Mutual Recursion）
--------------------------------------------------------------------------------

多个函数可以互相调用彼此，形成递归环。例如判断奇偶数：

.. code:: haskell

   isEven :: Integral a => a -> Bool
   isEven 0 = True
   isEven n = isOdd (abs n - 1)

   isOdd :: Integral a => a -> Bool
   isOdd 0 = False
   isOdd n = isEven (abs n - 1)

GHC 编译器能完美处理相互依赖的递归定义，自动构建相互调用的闭包。

递归 vs 余递归（Corecursion）
--------------------------------------------------------------------------------

在 Haskell 中，除了从大规模问题逐步收敛到终止条件的“递归”，还存在一种反向的强大计算模型——\ **余递归（Corecursion）**\ 。

- **递归（Recursion）**\ ：面向\ **消耗**\ 与\ **归纳（Induction）**\ ，逐步变小，朝向有限的基准条件终止。
- **余递归（Corecursion）**\ ：面向\ **生产**\ 与\ **余归纳（Coinduction）**\ ，从初始种子出发不断向前生成无限数据流，具有“高产性”（Productivity）。

结合惰性求值，余递归能极简地生成无限流：

.. code:: haskell

   -- 无限重复流（余递归）：
   myRepeat :: a -> [a]
   myRepeat x = x : myRepeat x

   -- 经典双向引用的斐波那契无限流：
   fibs :: [Integer]
   fibs = 0 : 1 : zipWith (+) fibs (tail fibs)

下游消费者只需调用 ``take 10 fibs``\ ，惰性求值就会驱动余递归精准生成前 10 项，按需停机。

发散与底（Bottom / ⊥）
--------------------------------------------------------------------------------

在类型理论中，\ **底**\ （写作 ⊥ 或 Bottom）指代那些\ **无法计算出有效结果的计算**\ 。主要表现为两种情况：

1. **非终止计算**\ ：无限死循环（发散）。
2. **运行时异常**\ ：例如调用了标准库中的 ``error "msg"`` 或 ``undefined``\ 。

.. code:: text

   ghci> let loop = loop in loop
   -- 挂起，永不返回，对应底

偏函数（Partial Functions）之殇
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

如果一个函数在某些合法类型输入下没有定义对应的返回值（即会抛出异常或返回底），该函数就被称为\ **偏函数**\ 。

标准库中的 ``head`` 就是典型的偏函数：

.. code:: text

   ghci> head []
   *** Exception: Prelude.head: empty list

在生产实践中，偏函数是运行期崩溃的主要源头之一。Haskell 提倡编写\ **全函数（Total Functions）**\ ，即对域内的所有输入都有明确的安全输出（通过类型系统如 ``Maybe`` 与 ``Either`` 承载所有可能性）。

小结
--------------------------------------------------------------------------------

- 递归是纯函数式语言中表达循环计算的唯一纯粹形式。
- 普通递归易堆积栈空间，尾递归配合严格累加器（Accumulator）可实现常数空间迭代。
- 余递归从局部种子生产潜在无限的数据流，由惰性消费者决定最终截取长度。
- 坚决规避偏函数与运行时底（⊥），用全函数与强类型代数容器构建可靠系统。
